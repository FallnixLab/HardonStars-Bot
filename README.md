# Hardon Stars

Telegram-магазин на Aiogram 3 для заказа Telegram Stars и Telegram Premium. В проекте есть профиль, история заказов, информационные разделы по присланному макету, кнопка Hardon Project, нативная оплата Telegram Stars и заготовки API-адаптеров для Crypto Pay, PayHot и xRocket.

## Запуск

Нужен Python 3.11 или новее.

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
```

Заполните `.env`, затем запустите:

```powershell
python main.py
```

Для фонового запуска на Windows можно запустить `run_forever.py`: он перезапускает бота с паузой, если Telegram API временно недоступен.

## Перед приёмом оплат

- Укажите `BOT_TOKEN` от BotFather.
- Заполните цены в RUB и отдельные цены для нативной оплаты Telegram Stars (XTR). Значение `0` намеренно блокирует создание заказа.
- Заполните токены Crypto Pay, PayHot и xRocket только если будете использовать их для отдельного физического товара или магазина вне Telegram. Эти провайдеры не отображаются в оплате Stars/Premium внутри бота.
- Для Crypto Pay оставьте `CRYPTO_PAY_ACCEPTED_ASSETS` пустым: API принимает все поддерживаемые криптовалюты по умолчанию. Сейчас в документации указаны USDT, TON, BTC, ETH, LTC, BNB, TRX и USDC.
- Для xRocket оставьте `XROCKET_PAY_CURRENCIES` пустым: код не отправляет ограничивающий список. В документации сказано, что при явной передаче `payCurrencies` мультивалютный инвойс не поддерживается и допускается одна валюта, совпадающая с `priceCurrency`; набор валют в режиме по умолчанию нужно подтвердить в тестовом приложении xRocket.
- Добавьте ссылку поддержки и окончательные тексты/ссылки правил, политики и соглашения.
- После подтверждения API-хоста и потока Fragment укажите `FRAGMENT_API_BASE_URL`, `FRAGMENT_WALLET_SEED` и вручную включите `FRAGMENT_ENABLED=true`. Это секрет от кошелька оператора; храните `.env` только на сервере и не отправляйте его в переписку или Git.
- Проверьте Fragment, все платёжные способы и цены в тестовых режимах до включения реальных платежей.

Telegram требует принимать оплату за цифровые товары, продаваемые внутри ботов и Mini Apps, только в Stars (`XTR`). Поэтому для Stars и Premium в текущем боте показывается только нативная оплата Telegram Stars. CryptoBot, PayHot и xRocket не предлагаются в чекауте этих товаров.

Заказы хранятся в SQLite. Повторные callback-обновления не запускают выдачу второй раз. После подтверждения платежа, если API выдачи вернул неоднозначную ошибку или таймаут, заказ переводится в `paid_issue` для ручной проверки — бот не повторяет потенциально успешную транзакцию автоматически.

## Текущие границы интеграции

- Адаптер выдачи Stars/Premium написан под опубликованный интерфейс пакета `fragment-stars-api`: операции требуют операторский seed и расходуют средства его кошелька после подтверждения оплаты клиента. Хост из документации пакета (`fragment-api.ydns.eu`) отличается от API-хоста, на который ссылается веб-приложение документации (`api.fragment-api.com`). Поэтому интеграция выключена по умолчанию: перед включением подтвердите у Fragment, какой API-хост и SDK относятся к вашему аккаунту.
- Экран «Баланс TON» уже добавлен, но пополнение оставлено отключённым: в доступном SDK-контракте не подтверждён метод выдачи/перевода TON. Перед включением нужно сверить нужный метод и формат адреса с документацией вашего Fragment API аккаунта.
- PayHot API принимает `card`, `sbp` и `crypto`; ERIP пока не добавлен. Для СБП используется один код метода `sbp`, валюта RUB. Включённость способов зависит от проекта PayHot.
- Переданные Premium Emoji ID уже используются в сообщениях. Bot API также поддерживает `icon_custom_emoji_id` для кнопок; кнопочные иконки можно использовать, когда соответствующие кнопки оплаты появятся для товара, который можно продавать через внешний провайдер.
- Информационные страницы содержат стартовый текст. Перед запуском заполните юридические условия и контакты в `.env`/текстах проекта.

## Премиум-эмодзи

В сообщениях подключены ID, которые вы прислали: xRocket, CryptoBot, PayHot СБП, PayHot карта и PayHot криптовалюта. ID для ЕРИП можно добавить после подключения способа и получения emoji.
